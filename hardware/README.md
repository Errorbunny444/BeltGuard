# Hardware prototype

The component list is derived from the supplied main ESP32 sketch and camera usage in Python. See [components and signal pins](components.md). No physical wiring diagram, measured calibration record or prototype-rig photograph was supplied. Supplied edge-dashboard, main-dashboard and Unity reference screenshots are indexed in `docs/screenshots/README.md`.

Unity fields for motor current, speed, encoder position and damage severity belong to its simulation/input schema. They are not treated as proof that corresponding sensors are installed on the physical rig.
